# Financial Dashboard - CloudCash

Современное финансовое приложение с микрофронтенд-архитектурой.

## Структура проекта

```
microfrontends/
├── react_host/              # Хост-приложение
│   ├── src/                 
│   │   ├── components/      
│   │   │   ├── Sidebar.tsx  # Боковое навигационное меню с React Router
│   │   │   ├── Header.tsx   # Заголовок с профилем пользователя
│   │   │   └── CardSection.tsx  # Отображение карт и баланса
│   │   ├── pages/          
│   │   │   ├── Overview.tsx     # Главная страница
│   │   │   ├── Transactions.tsx # Страница транзакций
│   │   │   ├── Cards.tsx        # Страница управления картами
│   │   │   ├── Invoices.tsx     # Страница счетов и квитанций
│   │   │   ├── Goals.tsx        # Страница финансовых целей
│   │   │   └── Settings.tsx     # Страница настроек
│   │   ├── moduleFederation/  # Интеграция с микрофронтендом
│   │   │   ├── modules.tsx  # Загрузка удаленных модулей
│   │   │   └── ErrorBoundary.tsx  # Обработка ошибок при загрузке микрофронтендов
│   │   ├── App.tsx
│   │   └── bootstrap.tsx    # Точка инициализации приложения
│
├── react_front/             # Микрофронтенд
│   ├── src/
│   │   ├── components/
│   │   │   ├── GoalsSection.tsx       # Секция целей
│   │   │   ├── StatisticsSection.tsx  # Статистика расходов
│   │   │   ├── TransactionsSection.tsx # История транзакций
│   │   │   └── NewTransactionSection.tsx # Форма для новой транзакции
│   │   ├── pages/
│   │   │   ├── Dashboard.tsx          # Объединяет все секции
│   │   │   ├── FinancialGoals.tsx     # Страница целей
│   │   │   ├── Statistics.tsx         # Страница статистики
│   │   │   ├── TransactionHistory.tsx # Страница истории транзакций
│   │   │   └── NewTransaction.tsx     # Страница новой транзакции
│   │   ├── App.tsx
│   │   └── bootstrap.tsx    # Инициализация и экспорт функции mount
```

## Разделение ответственности

### Хост-приложение (react_host)

-  **Основной функционал:**
   -  Базовая разметка страницы (layout)
   -  Маршрутизация между основными страницами
   -  Боковое меню навигации с React Router
   -  Заголовок с профилем пользователя
   -  Секция карт и баланса
   -  Индивидуальные страницы для каждого пункта меню
   -  Управление интеграцией микрофронтенда

### Микрофронтенд (react_front)

-  **Основной функционал:**
   -  Секция целей (Goals)
   -  Статистика расходов (Outcome Statistics)
   -  История транзакций (Transaction history)
   -  Форма для создания новой транзакции (New transaction)
   -  Внутренняя маршрутизация между компонентами

## Технологический стек

-  React 18 с TypeScript
-  React Router DOM 7 для маршрутизации
-  Module Federation для реализации микрофронтенд-архитектуры
-  CSS с использованием переменных для единого стиля
-  Адаптивная верстка с поддержкой мобильных устройств
-  SVG-иконки для всех графических элементов интерфейса

## Интеграция и взаимодействие

-  Хост-приложение предоставляет базовый макет и навигацию
-  Микрофронтенд загружается динамически и может использоваться как в составе хоста, так и отдельно
-  На странице Goals хост-приложение использует компонент микрофронтенда для отображения секции целей
-  Компоненты микрофронтенда экспортируются с помощью Module Federation и импортируются в хост-приложение

## Запуск проекта

1. Установить зависимости: `yarn install` в каждой директории
2. Запустить микрофронтенд: `yarn start` в директории react_front (порт 3001)
3. Запустить хост: `yarn start` в директории react_host (порт 3000)
4. Открыть в браузере: http://localhost:3000
